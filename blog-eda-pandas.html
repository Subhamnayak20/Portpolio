Exploratory Data Analysis Using pandas

Before modelling or building a dashboard, you need to know what is in your data. This is a checklist-style routine you can reuse on most tabular datasets.

2 min read

The example dataset

The code assumes a CSV called sales.csv with the columns order_date, region, category and amount. Replace it with your own file and column names.

1. Load and look at the structure

Python
import pandas as pd

df = pd.read_csv("sales.csv", parse_dates=["order_date"])

print(df.shape)     # (rows, columns)
print(df.head())    # first five rows
df.info()           # column names, types, non-null counts

You are checking the number of rows and columns, whether dates were parsed as dates, and whether numbers were read as numbers instead of text.

2. Missing values and duplicates

Python
print(df.isna().sum())          # missing values per column
print(df.duplicated().sum())    # number of fully duplicated rows

df = df.drop_duplicates()

# One option for a numeric column: fill with the median
df["amount"] = df["amount"].fillna(df["amount"].median())

There is no single right way to handle missing values. Dropping rows, filling with the median, or leaving them as missing can all be correct, depending on how many are missing and why. Write down the choice you make.

3. Clean text and fix types

Python
df["region"] = df["region"].str.strip().str.title()
df["category"] = df["category"].str.strip().str.title()
df["amount"] = pd.to_numeric(df["amount"], errors="coerce")  # bad values become NaN

Inconsistent labels such as "north", "North " and "NORTH" would otherwise be counted as three different regions.

4. Understand distributions and categories

Python
import matplotlib.pyplot as plt

print(df["amount"].describe())          # count, mean, std, quartiles, min, max
print(df["region"].value_counts())      # rows per region

df["amount"].plot(kind="hist", bins=30, title="Order amount")
plt.show()

5. Summarise by group and over time

Python
by_region = (
    df.groupby("region")["amount"]
      .agg(["count", "mean", "median", "sum"])
      .sort_values("sum", ascending=False)
)
print(by_region)

monthly = df.set_index("order_date")["amount"].resample("MS").sum()
monthly.plot(title="Monthly revenue")
plt.show()

resample needs a datetime index. "MS" groups by calendar month, labelled by the first day of the month.

6. Look for outliers

The interquartile range (IQR) rule flags values more than 1.5 × IQR below the first quartile or above the third quartile.

Python
q1, q3 = df["amount"].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr

outliers = df[(df["amount"] < lower) | (df["amount"] > upper)]
print(len(outliers), "possible outliers")

df.boxplot(column="amount", by="region")
plt.show()

An outlier is not automatically an error. Check whether it is a typo, a rare but genuine event, or an important case before removing it.

7. Check relationships

Python
numeric = df.select_dtypes(include="number")
print(numeric.corr())

A correlation coefficient measures linear association only, and correlation does not imply causation.

EDA checklist

  • Shape, column types and a few sample rows.
  • Missing values and duplicates, with a note of what you did.
  • Category labels and date formats are consistent.
  • Distributions, ranges and outliers of the important numeric columns.
  • Summaries by the groups that matter to the question.
  • A short list of findings and open questions to take into modelling or reporting.
